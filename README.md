# 세움 · SEUM

**상속·증여·양도 세무 문제를 공식 근거와 함께 검토하는 모바일 웹앱**

[앱 바로가기](https://seum-tax-kr.kbj060813.chatgpt.site)

아이폰·안드로이드·PC 브라우저에서 설치 없이 이용할 수 있습니다. 고객은 로그인 없이 질문하고, AI가 검색한 세법·판례를 바탕으로 안내를 받습니다. 판단이 모호하거나 근거가 충돌하는 부분은 전문가 검토란으로 분리합니다.

## 주요 기능

| 기능 | 제공하는 내용 |
| --- | --- |
| 세액 계산 | 상황 설명 → AI·RAG로 적용 조건과 입력 초안 검토 → 사용자가 금액 확인·수정 → 서버 계산 코드로 산출세액 계산 |
| 판례·쟁점 | 법령·예규·해석례·판례·결정례 검색, 쟁점 탐색, 우리 사례와 공통점·차이점·적용 시점 비교 |
| AI 컨설팅 | 이전 대화를 이어받는 챗봇 상담, 근거 출처, 권장 진행 순서와 추가 확인 질문 제공 |
| 전문가 검토 | 사실관계 누락·해석 충돌·적용 시점 불명확·근거 부족 등을 별도 관리하고 담당자가 검토 |

### 세액 계산

AI는 질문에서 재산·관계·거래 시점 등을 파악하고, 검색한 공식 근거를 이용해 계산 조건과 입력값을 제안합니다. 고객이 말한 금액은 원문과 단위를 코드로 대조하며, 확인되지 않은 값은 비워 둡니다.

사용자가 입력 초안을 확인·수정하고 계산 가정에 동의하면 서버에서 정수 원 단위로 계산합니다. 최종 입력과 계산 결과는 해당 검토 기록에 저장합니다. 세법 검토와 입력 초안 생성은 단계별 요청으로 나누어 처리합니다.

현재 계산 엔진은 **2026년 일반 기본세율 시나리오**를 지원합니다.

| 세목 | 계산에 사용하는 입력 |
| --- | --- |
| 상속세·증여세 | 재산가액, 채무 등 차감액, 합산 사전증여액, 공제 합계액 |
| 양도소득세 | 양도가액, 취득가액, 필요경비, 확인된 장기보유특별공제액, 기본공제 잔여액 |

세액공제, 세대생략 할증, 중과·단기보유 등 별도 세율, 비과세·감면, 가산세와 특례는 자동 확정하지 않습니다. 양도 지방소득세는 국세 산출액의 10%로 단순 추정합니다. 결과는 신고 납부세액 확정값이 아닌 계산 시나리오입니다.

### 판례·쟁점과 AI 상담

쟁점 지도는 24개 탐색 분류를 제공합니다. 검색 결과에서 원문과 출처를 확인하고, AI 비교 분석으로 유사 사례와 다른 사실관계 및 적용 조건을 살펴볼 수 있습니다.

AI 컨설팅은 대화형 챗봇으로 동작합니다. 질문과 이전 대화를 바탕으로 근거를 검색해 검토 내용·권장 행동·추가 질문을 제시합니다. 확인된 근거 ID를 인용하도록 응답을 검사합니다.

### 전문가 검토

불명확한 사실관계, 자료 간 충돌, 법령 적용 시점, 판결 확정 상태와 근거 부족을 별도 검토 항목으로 남깁니다. 고객에게 보이는 검토 현황과 담당자 전용 `/expert` 화면을 구분합니다.

담당자는 질문·대화·AI 안내·비교 근거·계산 초안·계산 결과를 확인하고 다음 작업을 수행합니다.

- 검토 중·추가 정보 필요·검토 완료 상태 관리
- 내부 메모와 고객 전달 의견을 구분해 작성
- 최종 검토 확인 후 완료 처리

내부 메모는 고객 API 응답에서 제외합니다. 담당자 화면은 호스팅 플랫폼 인증 정보와 서버의 이메일 허용 목록으로 보호하며, 동시 수정은 버전으로 검사합니다. AI가 검토 항목을 분리하는 것과 실제 전문가가 검토를 완료하는 것은 별개입니다.

## AI·RAG 처리 방식

```text
질문·이전 대화·거래 기준일
  → AI 검색어·쟁점 분류
  → 국세청 공개 자료 조회 + OpenAI Vector Store 검색
  → 원문·연결 조문·법령 연혁 확인
  → AI 관련성 평가
  → 근거를 인용한 안내·비교·추가 질문
  → 모호하거나 충돌하는 부분을 전문가 검토로 분리
```

### 연결된 자료

국세청 국세법령정보시스템의 공개 검색·상세 화면이 사용하는 읽기 전용 요청으로 자료를 조회합니다.

- 법령·시행령·시행규칙
- 예규·세법 해석례
- 법원 판례·행정 결정례
- 등록된 공식 원문 벡터 색인

검색 목록의 요약과 실제 확보한 원문을 구별합니다. 법령은 거래 기준일에 맞는 연혁을 선택하고 조문에 속한 항·호를 연결해 읽습니다. 관련 조문을 추가 조회하며 출처 식별자·사건번호·확인 시점을 함께 관리합니다.

초기 벡터 색인은 공식 자료 **5건**입니다. 전체 세법·판례를 벡터 DB에 수록한 구조가 아니라 실시간 공식 검색과 기존 색인을 함께 사용하는 구조입니다. 검색 캐시는 목록 15분, 상세 본문 6시간입니다.

공식 자료 조회에는 제한된 재시도와 시간 제한을 적용합니다. 검색이나 원문 확보에 실패하면 누락·한계를 표시하고 전문가 확인이 필요한 항목으로 남깁니다. 전체 자료의 완전성이나 모든 쟁점의 최신·정확한 해석을 보장하지 않습니다.

## 로컬 실행

Node.js 24 이상과 npm이 필요합니다.

```bash
npm ci
npm run build
npm test
npm run dev
```

기본 미리보기 주소는 `http://127.0.0.1:5190`입니다. 기본 실행은 API 키를 자동으로 불러오지 않습니다.

실제 AI 기능을 사용하려면 `.env.example`을 참고해 Git에서 제외되는 `.env.local`을 작성한 뒤 명시적으로 활성화합니다.

```powershell
$env:SEUM_USE_ENV_FILE = '1'
npm run dev
```

실시간 공식 검색을 사용하려면 `SEUM_LIVE_RESEARCH=true`를 설정합니다. 새 계정의 벡터 검색에는 해당 계정에서 사용할 수 있는 별도 색인이 필요합니다.

### 환경 변수

| 이름 | 용도 |
| --- | --- |
| `OPENAI_API_KEY` | 서버에서만 사용하는 OpenAI 비밀 키 |
| `OPENAI_MODEL` | 사용할 모델, 기본값 `gpt-4.1-mini` |
| `OPENAI_ORGANIZATION` | 필요한 경우 키 발급 조직 지정 |
| `SEUM_LIVE_RESEARCH` | `true`이면 국세청 공개 검색 활성화 |
| `OPENAI_VECTOR_STORE_ID` | 사용할 벡터 저장소 ID, 미지정 시 기존 D1 설정 확인 |
| `EXPERT_EMAILS` | 전문가 화면 접근을 허용할 담당자 이메일 목록 |
| `DB` | 운영 환경의 D1 바인딩 |

운영 비밀값은 호스팅 보안 환경 변수로 관리합니다. 실제 키를 README·소스·배포 manifest에 넣지 않습니다.

## 데이터와 접근 관리

- 고객은 로그인 없이 이용하며, 세션 쿠키를 기준으로 상담·대화 소유권을 확인합니다.
- 고객의 질문·대화·검색 근거는 AI 처리에 사용되며 OpenAI 요청에 `store: false`를 지정합니다. 이것이 앱의 상담 DB 저장을 끄는 설정은 아닙니다.
- 고객 연락처는 모델 입력에서 제외합니다. 공식 검색어에는 개인정보를 제외한 법률 쟁점만 사용하도록 처리합니다.
- 주민등록번호·계좌번호 등 민감정보는 입력하지 않아야 합니다. AI의 검색어 변환이 완전한 개인정보 익명화를 보장하지는 않습니다.
- `.env.local`, 로컬 상담 DB·로그·검증 산출물과 `.local/`은 Git에서 제외합니다. `.env.example`에는 실제 키가 없습니다.
- 공개 앱의 AI 사용 비용은 연결된 OpenAI 계정에 발생합니다. 서버에 일일 이용량 제한을 적용합니다.
- 고객 계정 기반 복구는 제공하지 않으므로 쿠키 삭제·브라우저 변경 시 기존 상담 접근이 유지되지 않을 수 있습니다.

## 검증

2026-11-02 배포 기준으로 빌드와 서버 테스트 **28개**가 통과했습니다. GitHub Actions는 푸시·PR마다 Node.js 24에서 설치·빌드·서버 테스트를 실행합니다.

검증 항목은 세율 경계값, 정수 금액 계산, 한국어 금액 단위 대조, 확인되지 않은 값의 자동 입력 방지, 인용 검증, 상담 소유권, 대화 흐름과 전문가 정보 분리 등을 포함합니다.

```bash
npm run build
npm test
```

UI 검증 스크립트는 Windows에 설치된 Chrome을 사용합니다. 모의 AI 응답을 사용하는 UI 검사와 실제 API 검증은 구분합니다.

```bash
node tests/browser-chat.mjs
node tests/browser-research.mjs
node tests/browser-workspace.mjs
```

실제 배포된 모바일 화면에서도 OpenAI 응답, 국세청 원문 근거, 세액 계산, 판례·세법 비교와 비인증 사용자의 전문가 API 접근 차단을 확인했습니다. 검증 사례는 가상 사례이며, 테스트 통과가 모든 세무 해석의 정확성을 보증하지는 않습니다.

## 배포

현재 앱은 Sites에서 운영합니다. 기존 `.openai/hosting.json`의 프로젝트를 유지하고 소스 동기화 → 빌드·검증 → 산출물 저장 → 버전 배포 순서로 반영합니다. DB 마이그레이션은 배포 과정에서 적용합니다.

GitHub Actions는 빌드·테스트용이며 GitHub 푸시만으로 운영 앱이 자동 배포되는 구성은 아닙니다.

## 현재 범위와 후속 작업

자동 신고·납부, 이메일·문자 알림, 전문가 자동 배정, 고객 계정 복구와 운영용 데이터 보존·삭제 UI는 제공하지 않습니다. 국세청 원문 사이트의 구조 변경과 자료 조회 상태를 지속적으로 점검해야 합니다.

실제 서비스 운영 전 개인정보 처리방침·보유기간·삭제 절차와 담당 전문가 운영 체계를 확정해야 합니다. AI 안내와 계산 시나리오는 검토를 돕는 초안이며, 최종 세무 판단은 확인된 사실관계와 적용 법령을 바탕으로 담당 전문가가 수행합니다.
